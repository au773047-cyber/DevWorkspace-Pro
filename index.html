About DevWorkspace Pro

This is Milestone 1: a browser IDE foundation with local file editing, autosave, preview, and ZIP import/export.

A real shell terminal, server-side runtime, remote filesystem, and Git push/pull require a secured backend and are not implemented in this frontend-only milestone.
